# Devixo Solutions — Personal Portfolio Website

## Project Overview
A professional, responsive personal portfolio website developed as Task 01 of the Devixo Solutions Web Development Internship Program.

## Objective
To create a clean and attractive personal portfolio that showcases my profile, technical skills, education, projects, and contact information.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox and Grid
- Media queries for responsive design

No Bootstrap, Tailwind CSS, or pre-built website templates were used.

## Features
- Home and introduction section
- About Me section
- Technical Skills
- Education
- Three project showcases
- Contact form interface
- Smooth scrolling
- Hover effects
- Responsive layout for different screen sizes

## Projects
1. Analytics Dashboard
2. FieldOps PWA
3. Beautify — Home Beauty Services

## Project Structure
- `index.html` — Website structure
- `style.css` — Website styling
- `screenshots/` — Website screenshots
- `Project_Report.pdf` — Project documentation
